> *Paperboat made you feel something before you tasted it.*

**Creative Territory: "Vivid Craft"**
Bold product colours as the visual lead. Warm Indian storytelling as the emotional layer.
Food science credibility as the closing argument. All three must coexist on every page.

### Voice Definition
| Attribute | Description |
|---|---|
| **Tone** | Warm like a founder talking over chai — precise like a food technologist |
| **Never** | Salesy, generic, cold, buzzword-heavy, or exaggerated |
| **Always** | Grounded in real craft, real science, and real Goa |

## DESIGN SYSTEM

### The Core Principle — "Colour Is the Narrative"
Frugel has no single fixed brand colour beyond its red logo.
**The products ARE the colour system.** Every section's background tint is pulled from
the hero product in that section. The page literally changes colour as you scroll.
This is the scroll storytelling — colour is the narrative thread.

### The Produce Palette
```
Crushes & Syrups   →  Tropical amber, berry purple, emerald, cobalt, rose gold
Glaze Gel          →  Rich caramel, midnight cocoa, blueberry ink, mango gold
Fondant            →  Chalk pastels — soft, playful, craft-table energy
Fruit Filling      →  Cherry red, blueberry deep, strawberry blush
Fruit Jam          →  Burnt orange, warm marmalade, deep plum
Chocolate Sauce    →  Deep espresso brown, near-black with warm undertones
Origin / Goa       →  Terracotta, sand, cashew cream, coastal teal
Dark Sections      →  #1A120A (warm near-black — not cold black)
Light Sections     →  #FDF6EC (warm cream — not clinical white)
```

### Typography System
```
DISPLAY — Headlines
Font     : Cormorant Garamond or Playfair Display
Weight   : Bold / SemiBold
Role     : All H1, H2 headings — warm, editorial, characterful
Feel     : Old Goan signage meets modern food magazine

BODY — Copy, specs, descriptions
Font     : Inter or DM Sans
Weight   : Regular / Medium
Role     : All body copy, product descriptions, UI labels
Feel     : Food technologist's precision — clean, legible, no fluff

SOUL — Accent, taglines, pull quotes
Font     : A flowing script — Saudagar, Sacramento, or custom brush
Weight   : Regular
Role     : "Taste Meets Soul", section transitions, emotional moments ONLY
Feel     : The brand's heartbeat — used sparingly, maximum impact
```

### The Drip Motif
The red drip from the Frugel logo is a recurring design element — not just a logo detail.
```
Usage:
- Section dividers: a subtle drip line between sections
- Logo animation: drip falls and forms the logo on page load
- Hover states: product cards get a drip accent on hover
- Pull quotes: drip mark as a quotation device
- Footer: large drip backdrop behind the tagline
```

### Texture & Depth
Inspired by Paperboat's tactile digital language:
```
- Grain/noise overlay (3–6% opacity) on all sections — prevents cold digital feel
- Illustrated fruit elements as background texture (cashews, mangoes, berries)
  — subtle, low-opacity, not clipart
- Slight inner shadow on section edges — depth without hard dividers
- Product photography always shot mid-action, never static catalogue style
```

### Photography Direction
| Category | Hero Shot Direction |
|---|---|
| Glaze Gel | Slow dramatic pour over a dark cake — gel catching rim light |
| Crushes | Bottle tilted, liquid splashing into glass with visible fruit |
| Syrups | Thin stream swirling into ice-filled cocktail glass, jewel tones |
| Fruit Filling | Spoon lifting thick scoop — fruit pieces clearly visible |
| Fondant | Hands shaping a piece — warmth, craft, human touch |
| Jam | Spreading slowly on warm bread — texture, steam, colour |
| Chocolate Sauce | Classic drizzle — dark sauce, dramatic backlight, brownie below |
| Whole Fruit Crush | Backlit 1 Ltr bottle — fruit chunks suspended, almost scientific |

**The rule:** You should be able to feel the texture of every product from the image alone.

## SCROLL STORY & NARRATIVE ARC

The page is one continuous journey — not sections bolted together.
The visitor moves through 5 emotional stages:

```
STAGE 1 — IMPACT         (Hero)
Products hit immediately. Bold, full-bleed, alive.
"Taste Meets Soul" — felt before read.
Visitor thinks: "This is different."

STAGE 2 — DISCOVERY      (Product River + Origin)
Colours shift as the range reveals itself.
Goa arrives — the farm, the factory, the place.
Visitor thinks: "I've never seen a range like this."

STAGE 3 — UNDERSTANDING  (The Problem + Innovation)
Why Frugel exists — the post-harvest story.
The Whole Fruit Chunks innovation.
Visitor thinks: "These people actually care about what they make."

STAGE 4 — TRUST          (Founders + Why Partner)
Real people. Real credentials. Real network.
Visitor thinks: "These are food professionals I can rely on."

STAGE 5 — ACTION         (Network + Enquiry)
Natural, not forced. Conversation, not conversion.
Visitor thinks: "I need to talk to them."

BOOKEND                  (Footer)
"Taste Meets Soul" closes what it opened.
The promise the scroll fulfilled.
```

### Animation Spec
| Element | Animation | GSAP Method | Timing |
|---|---|---|---|
| **Logo drip** | Red path draws downward, logo fades in as drip completes | SVG `stroke-dashoffset` → `opacity` reveal | On load, 0–1.2s |
| **"Taste Meets Soul"** | Fades in like breath on glass — `opacity 0→1`, very slow | `gsap.to`, ease `power1.inOut` | 1.2s delay |
| **Headline words** | Word-by-word split reveal, slight rise | `SplitText` stagger 0.08s, `y: 20→0` | 1.8s delay |
| **Body copy** | Fade up as block | `opacity 0→1`, `y: 15→0` | 2.3s delay |
| **CTA buttons** | Stagger fade up | `stagger: 0.15s` | 2.6s delay |
| **Product arrangement** | Subtle slow float — products drift 6px up and down | `gsap.to` yoyo loop, ease `sine.inOut` | Continuous after load |
| **Background** | Warm near-black with faint grain texture overlay | CSS + noise SVG filter | Static |
| **Scroll indicator** | Gentle bounce arrow | CSS `@keyframes` bounce | 3s delay |

### Animation Spec
| Element | Animation | GSAP Method | Timing |
|---|---|---|---|
| **Background shift** | Warm cream → deep forest green | `ScrollTrigger` color tween | On section enter |
| Eyebrow | Slide in from left | `x: -30→0`, `opacity: 0→1` | On enter |
| Headline lines | Word split reveal | `SplitText`, stagger 0.06s | After eyebrow |
| Body paragraphs | Fade up in sequence | `ScrollTrigger` batch | On scroll |
| **Fruit icons falling** | SVG cashews, mangoes, kokum fall from top, fade out | `y: -100→300`, `opacity: 1→0`, stagger | On section pin |
| **Fruit → bottle morph** | Falling fruit reassemble into Frugel bottle shape | GSAP `MorphSVG` or opacity swap | After fall completes |
| **Counter Card 1** | Counts 0 → 40 | Custom counter + `ScrollTrigger` | On card enter |
| **Counter Card 2** | Counts 0 → 92,000 | Same, faster tick | On card enter |
| **Counter Card 3** | Counts 0 → 500 | Same | On card enter |
| Data cards | Stagger slide up | `y: 40→0`, stagger 0.2s | On scroll |
| Transition line | Fade in + italic slide | `opacity: 0→1` | Last in section |

**Developer note:**
- Section should **pin for ~60% of scroll** while fruit-fall animation plays
- Counter: `Math.ceil(progress * targetValue)` on ScrollTrigger update callback
- Deep green colour: `#1C2B1A`

## GLOBAL ANIMATION PRINCIPLES

### Performance Rules
```
- Use scrub: 1 or scrub: 1.5 — never boolean true (janky)
- will-change: transform on continuously animating elements
- ScrollTrigger.batch() for DOM-heavy stagger animations
- Animate only transform and opacity — never width/height/margin
- Kill all ScrollTrigger instances on component unmount (React useEffect cleanup)
- Lazy-load all images below fold — use Intersection Observer or Next.js Image
```

### Easing Reference
| Use Case | Easing |
|---|---|
| Cards entering | `power2.out` |
| Bounce / playful (icons, chips) | `back.out(1.4)` |
| Scrub animations | `none` |
| Dramatic text reveal | `expo.out` |
| Subtle hover | `power1.inOut` |
| Typewriter chars | `none` (linear) |
| Logo drip | `power3.inOut` |

### Section Scroll Behaviour
```
Section 01 — Hero              : Pin 20% scroll → release
Section 02 — Product River     : Normal scroll, stagger triggers
Section 03 — Origin / Goa      : Pin for map draw (~80% scroll)
Section 04 — The Problem       : Pin for fruit fall (~60% scroll)
Section 05 — Innovation        : Normal scroll, spotlight entry
Section 06 — Founders          : Horizontal pin (~150% scroll length)
Section 07 — Why Partner       : Normal scroll, grid stagger
Section 08 — Dealer Network    : Pin for map animation (~80% scroll)
Section 09 — Enquiry           : Normal scroll
Section 10 — Footer            : Normal scroll
```

### Reduced Motion (Accessibility)
```css
@media (prefers-reduced-motion: reduce) {
  /* Show all final states immediately */
  /* Disable GSAP scroll triggers */
  /* Keep hover states as CSS transitions only */
}
```
Use `gsap.matchMedia()` to conditionally register all animations.
